# DeadlineOS

A countdown lock-screen generator built with HTML, CSS and JavaScript (no backend, no API).

**Goal:** Build My AI Project | **Deadline:** December 15, 2026

## Features

- Live countdown (days, hours, minutes, seconds) with progress bar
- Editable goal title and deadline
- Weekly milestones and a daily checklist (saved in the browser, checklist resets daily)
- Smartphone lock-screen wallpaper preview with three blue/purple themes
- One-click export of a 1080 x 1920 PNG wallpaper (HTML Canvas)
- Responsive layout for mobile and desktop

## Run locally

Open `index.html` in any modern browser. No installation needed.
